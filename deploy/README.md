# Приём заявок в Telegram

Форма на сайте отправляет заявку не напрямую в Telegram, а на промежуточный обработчик.
Так сделано намеренно: сайт статический, весь его JavaScript открыт для просмотра.
Если положить токен бота в страницу, любой посетитель сможет забрать его и прочитать
**все заявки с именами и телефонами** через `getUpdates`, а также писать от имени бота.
Обработчик хранит токен у себя, наружу он не попадает.

Бот уже создан: **@kakestsmmbot** («Заявки какестсмм»).

## Шаг 1. Узнать chat_id

Откройте бота в Telegram и отправьте ему любое сообщение — хотя бы `/start`.
Затем выполните, подставив токен:

```bash
curl -s "https://api.telegram.org/bot<ТОКЕН>/getUpdates" | grep -o '"chat":{"id":[-0-9]*'
```

Число после `"id":` — это `chat_id`. Если заявки должны падать в группу, добавьте
бота в неё, напишите сообщение в группе и возьмите `chat_id` оттуда (у групп он
отрицательный).

## Шаг 2. Развернуть обработчик

Бесплатно на Cloudflare Workers, карта не нужна.

1. Зарегистрируйтесь на `dash.cloudflare.com` → **Workers & Pages** → **Create** → **Worker**.
2. Назовите, например, `kakestsmm-leads`, нажмите **Deploy**.
3. **Edit code** → удалите содержимое → вставьте код из `telegram-worker.js` → **Deploy**.
4. **Settings → Variables and Secrets** → добавьте три переменные:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен от @BotFather |
| `CHAT_ID` | Secret | число из шага 1 |
| `ORIGIN` | Text | `https://kakestsmm.ru` |

`Secret` — важно: такие значения не показываются в интерфейсе после сохранения.

5. Скопируйте адрес воркера, он вида `https://kakestsmm-leads.<ваш-логин>.workers.dev`.

## Шаг 3. Подключить к сайту

В [`assets/js/main.js`](../assets/js/main.js) впишите адрес в константу:

```js
var LEAD_ENDPOINT = 'https://kakestsmm-leads.ваш-логин.workers.dev';
```

Закоммитьте и запушьте. Через минуту проверьте: откройте сайт, дождитесь попапа,
оставьте тестовую заявку — сообщение должно прийти в бот.

## Что уже предусмотрено

**Ловушка для спама.** В форме есть поле, скрытое от людей. Люди его не видят и не
заполняют, а автоматические скрипты заполняют почти всегда. Если поле не пустое,
обработчик молча отбрасывает заявку, отвечая «успешно», чтобы спамер не подобрал обход.

**Проверка телефона** — на стороне обработчика тоже, не только в браузере: запрос
к воркеру можно отправить и в обход формы.

**Честная ошибка.** Если заявка не ушла, посетитель видит «Не удалось отправить»
и кнопку написать напрямую, а не ложное «Заявка принята». Раньше форма показывала
успех всегда — так терялись бы все заявки при любом сбое.

**Ограничение по домену.** Обработчик отвечает только запросам с `ORIGIN`.
Это не защита от целенаправленной атаки — заголовок можно подделать, — но отсекает
чужие сайты, которые попытались бы слать через ваш воркер.

## Если заявок станет много спама

В Cloudflare: **Security → WAF → Rate limiting rules**, ограничить, например,
5 запросов с одного IP за 10 минут. На бесплатном тарифе доступно одно правило.

## Смена токена

Токен меняется у @BotFather командой `/revoke`. После этого достаточно обновить
переменную `BOT_TOKEN` в настройках воркера — трогать сайт не нужно.
